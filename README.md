# RC6-Encrypted-TCP-Distributed-System
Sistem distribuit P2P Hibrid peste TCP, transfer de mesaje și fișiere criptate point-to-point. Criptare simetrică RC6 (Mod CBC) scrisă 100% de la zero (fără biblioteci), chunking pentru a respecta MTU-ul rețelei, plus mecanism de Master pentru Host Discovery și distribuție de chei (KEK/DEK).
